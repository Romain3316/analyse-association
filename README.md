# analyse-association
# Diagnostic financier d'association

Application Streamlit permettant de saisir quelques données issues du bilan et du compte de résultat d'une association afin d'obtenir une première lecture de sa santé économique.

## Fonctionnalités
- saisie simplifiée des données
- calcul des soldes intermédiaires
- calcul du FRNG, BFR et de la trésorerie nette
- calcul des principaux ratios financiers
- commentaire automatique en langage simple
- export CSV simple
